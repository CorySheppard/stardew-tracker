# Stardew Tracker w/ API
A Stardew Valley bundle tracker using a RESTFUL API in the backend!

The RESTful API is created using PHP and Propel ORM. The frontend is created using VueJS and Bootstrap 4. This is entirely new to me, I'm just here to learn :D

Here's the resources I've used to learn so far:
- [PropelORM Documentation](https://propelorm.org/documentation)
- [Create a PHP REST API : Write a RESTful API from Scratch using Plain, Object-Oriented PHP and MySQL](https://youtu.be/X51KOJKrofU?si=A9Ax9uEGQVHNciU6)
- [VueJS Tutorial](https://vuejs.org/tutorial)
